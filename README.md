# Hemal Das — Portfolio

Personal portfolio of **Hemal Das**, full stack developer from Chattogram, Bangladesh.

**Live site (after deploy):** https://hemalsportfolio.netlify.app/

## What's inside

| Feature | How it works |
|---|---|
| Loading screen | Shows 3–5 seconds on every visit, GPU-only animation |
| Offline screen | Service worker serves a cute offline page + live "offline" toast |
| Live GitHub data | Repos, stars, followers and project cards fetched from the GitHub API (cached 30 min) |
| Live Dhaka clock | Updates every second on the home hero |
| Contact form | Sends to dashemal08@gmail.com via FormSubmit.co |
| SEO | Name-first titles, meta descriptions, JSON-LD Person/WebSite schema, sitemap, robots |
| Responsive | Mobile (320px) up to ultrawide (2560px), reduced-motion friendly |

## Pages

- `index.html` — Home
- `about/` — About me, skills, typewriter headline
- `projects/` — Realtime GitHub repositories
- `services/` — Pricing ($49 / $149 / $399 + extras)
- `contact/` — Contact form, FAQ, map

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```
